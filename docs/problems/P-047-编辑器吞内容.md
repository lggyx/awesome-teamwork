# P-047 编辑器吞内容

## 问题描述

"Jira has been consistently unreliable in the 10 years of using
it (both hosted and self hosted)... it eats comments and updates
all the time with various csrf or authentication errors."——
输入即丢失，用户被逼出"先写本地再粘贴"的习惯。与 P-036（协同覆盖）
不同：这是编辑链路自身的可靠性问题。

## 证据

- HN「Jira can't stop people from using it incorrectly」（98 分 /
  142 评论），moribvndvs 原文如上（含原文语法）
  https://news.ycombinator.com/item?id=37140883
- Confluence 编辑器（补充，18874707 帖）："my spacebar literally
  stopped working in their edit view"——编辑器基础交互都会失效。
- 飞书移动端（补充，App Store 评论 2026-11-20）：云文档调相机插图片时
  进程被杀、"图片没有插入文档中"——移动端输入链路直接丢内容。

## 现有方案为什么不够

输入可靠性没有被当核心质量门：草稿不自动保存、失败静默、
会话过期时直接丢内容。

## 可能的解决方向

编辑即持久（本地草稿自动保存、提交失败内容不丢、可恢复），
作为所有输入路径的质量红线。

# P-078 核心字段失灵动摇全局信任

## 问题描述

ClickUp 用户："It's completely unreliable for dates in all tasks, now,
instead of primarily having issues with recurring tasks."——日期是
任务系统的地基，地基失灵则上千条任务全部存疑。用户的结论是
"Run and find another option"。与 P-047（编辑器吞内容）同属
"基础数据可靠性"灾难，但发生在结构化字段层。

## 证据

- 2026-11-20 抓取的 iTunes RSS 评论原文

## 可能的解决方向

核心字段（日期/状态/指派）作为最高质量等级对待：任何失灵按
P0 事故响应。

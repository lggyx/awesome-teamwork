# P-074 移动端/跨端体验断层

## 问题描述

应用商店差评的公约数：移动端是"半成品网页套壳"（ClickUp："someone
started building an app, then slapped a web window into the parts they
didn't have time for yet"）、手势误触（Teams 滚动触发横滑回复）、
选 epic 不落库离开即回退（Jira，6 个月未修）、移动端缺网页版功能
（Trello 不能按到期日排序）、iPad 连 Cmd+Z 都失效（Confluence）、
两端导航心智模型不一致（Monday）。

## 证据

- 以上 6 条均来自 2026-11-20 抓取的 iTunes RSS 评论 JSON（每条引文见
  原始记录 docs/problems/_raw-research-round3-2026-11-20.md）

## 可能的解决方向

移动端以"完整任务处理"为验收标准而非"能打开"，跨端交互一致性
纳入发布检查单。

# P-122 组织层级与联邦缺失

## 问题描述

Gitea 四个高热请求同指一事：子组（381 👍）、组织/仓库/用户联邦
（261 👍）、实例间联邦状态（255 👍）、ActivityPub/ForgeFed（144 👍）。
大规模团队需要"组织→子组→项目"的层级与跨实例互通，
单实例平铺模型撑不住（与 P-026 缺团队层级、P-050 跨组织互通同族，
这是来自代码托管侧的强证据）。

## 证据

- 以上 4 条 Gitea issues 标题与热度实抓于 2026-11-22

## 可能的解决方向

组织层级 + 联邦协议（ActivityPub）作为架构选项，
权限与可见性按层级继承。

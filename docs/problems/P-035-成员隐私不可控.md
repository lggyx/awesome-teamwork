# P-035 成员隐私不可控

## 问题描述

两例：Rocket.Chat 的图片缩略图直接从第三方 URL 加载，发一张可控服务器
的图就能探测任何在线成员的 IP；Mattermost 自托管版向分析域名发遥测，
管理台和配置文件里都找不到开关。

## 证据

- Rocket.Chat#10606（19 👍 / 8 评论）："it allows malicious users to
  discover the IP address of any online user by sending them links to
  images on a server they control"
- Mattermost#16241（12 👍 / 12 评论）："I couldn't find how to disable
  this unwanted behavior (neither in the admin console nor in the
  configuration file)."

## 现有方案为什么不够

隐私默认不设防（代理加载外部资源）、遥测默认开启且无开关——
都违背"自托管=我控制"的用户预期。

## 可能的解决方向

默认代理加载外部媒体（不暴露成员 IP）；遥测默认关闭且开关显著。

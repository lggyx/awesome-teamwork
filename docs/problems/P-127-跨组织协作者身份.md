# P-127 跨组织协作者身份

## 问题描述

Gitea federation 讨论里点出真实用例："it would be very convenient for
the project manager to add users from other git hosts"——项目经理要
把外部组织的人加进来协作，但要的是**身份联邦**而非代码镜像
（"If you want to share repositories you should use the mirror feature"）。
与 P-050（实例互通）、P-122（联邦缺失）互补：这是 federation 的
用户故事层。

## 证据

- Gitea#1612（261 👍/43 评论）：kolaente / jonasfranz 评论原文

## 可能的解决方向

外部协作者身份（受限 guest + 联邦身份），按资源授权而非全实例账号。

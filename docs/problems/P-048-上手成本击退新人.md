# P-048 上手成本击退新人

## 问题描述

"I started to motivate one of our Junior developers to start using
Jira recently. But he quickly loses track and stops updating the
issue status, because he has to learn too many new things."——
工具复杂度直接吃掉数据质量：新人一放弃，状态就停在过期值上，
整板数据可信度崩塌。

## 证据

- PM StackExchange（score 12 / 6 回答），楼主原文如上

## 现有方案为什么不足

为熟练用户设计的复杂度没有"新人坡道"：首次使用没有引导性
最小流程，一步踏错就是一屏专业术语。

## 可能的解决方向

零配置开箱可用 + 渐进披露（新人只见三列看板与基本字段），
复杂能力随角色浮现。

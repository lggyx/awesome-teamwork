# P-039 无周期性任务

## 问题描述

运营/行政类团队的日常是大量周期性工作（周报、巡检、盘点），看板工具
不支持 recurrence，"It should be possible to define a recurrence
interval. For example: weekly repeat on monday at 20:00"——
Nextcloud Deck 全库热度第二的请求（103 👍），open 多年。

## 证据

- Deck#480（103 👍 / 46 评论，open）："It should be possible to define
  a recurrence interval. For example: weekly repeat on monday at 20:00"

## 现有方案为什么不够

周期性是日程工具的常识能力，任务工具普遍缺失；用户被迫在日历和
任务工具间两头维护同一件事。

## 可能的解决方向

任务原生支持 RRULE 式重复规则，完成即生成下期，历史留档可追溯。

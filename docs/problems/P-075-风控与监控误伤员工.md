# P-075 风控与监控误伤员工

## 问题描述

钉钉的风控/监控三连：在短时间内手动使用搜索被封号（"我的钉钉号近期
还被封了，原因竟是我在短时间内手动使用了搜索功能"）；办公中共享屏幕
触发连环验证；"如果你突然在某一天截图次数过多，钉钉系统检测到之后便会
立马上报给管理员"——工具从协作平台变成监控探头，员工在系统眼里是
嫌疑人。

## 证据

- 钉钉中国区 iOS App Store 评论（2026-11-20 抓取）：以上原文
- 钉钉国际版：Chromebook 登录/注册即锁号（"the new account is locked
  immediately"）

## 可能的解决方向

风控透明化（可解释的触发条件 + 申诉入口）；监控功能不默认开启、
对被监控方可见。

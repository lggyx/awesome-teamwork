# P-100 多语言与国际化缺位

## 问题描述

四源同证：BookStack "translations have no connection to each other
and all content in all languages appears to the user"（83 👍 / 80 评论，
closed 未实现）；Outline RTL 文字方向错误（26 👍）；Huly 无 RTL 支持
（"There's no support for RTL at this moment."）；Cal.com 预订页无法
手动指定语言。跨国/跨语言团队的知识与协作界面缺国际化底座。

## 证据

- 以上 4 条 issues 标题与热度实抓于 2026-11-20

## 可能的解决方向

内容带语言版本关联（翻译树），界面 RTL/本地化一等支持。

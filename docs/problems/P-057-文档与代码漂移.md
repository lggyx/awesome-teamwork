# P-057 文档与代码漂移

## 问题描述

"documentation isn't very good anywhere"——文档在各家公司普遍平庸，
且替别人的代码维护文档是 "a Sisyphean task"；代码越活跃，
"Looking after code documentation in this context is a pain"。
文档不是写完就完，是随代码持续腐烂。

## 证据

- HN 26446692（42/18）：如上两句原文
- HN 22489116（6/6）："Good codebase evolves all the time thru constant
  refactoring."
- 敏捷与文档的张力（补充，SE score 8/5 答）：10 人团队争论"敏捷方式下
  如何同时满足可维护性与知识传承"——漂移是流程与工具的联合缺口。

## 可能的解决方向

文档条目与代码/任务建立引用关系，变更时自动提示"受影响文档"。

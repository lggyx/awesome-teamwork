# P-026 缺团队/组织层级

## 问题描述

多个团队共用一个实例时，工具没有组织→团队→用户的层级概念：
看板归属、权限、成员可见范围全部平铺，管理员无法按团队授权，
成员被迫在一堆无关看板里游泳。

## 证据

- Wekan#802："Similar to Trello, an administrator would be able to create a
  Organization/Team/User"（要求组织/团队/用户三级结构）
- Rocket.Chat#658（补充，88 👍 / 163 评论，全库热度第一）："Transparently
  divide a single server into several different instances shared between
  different groups of users."——multi-tenancy 是同一痛点的服务器级形态。

## 现有方案为什么不够

单团队工具硬撑多团队场景；与 P-013（跨团队交接）互为表里——
结构上没有团队边界，流程上的跨团队协作更无从建模。

## 可能的解决方向

组织→团队→用户三级模型为基础，权限按团队边界默认收敛、显式开放。

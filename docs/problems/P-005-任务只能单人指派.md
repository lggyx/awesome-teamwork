# P-005 任务只能指派给一个人

## 问题描述

需要多人共同负责的任务（如安全响应小组）在工具里没有承载方式：单指派模型
逼着团队用评论@、拆假任务等变通手段，真实协作关系在系统里不可见。
Leantime 官方维护者回复承认"there isn't currently any way to work around
this need at present"。

## 证据

- Leantime#1099（25 评论 / 8 👍，长期开放后才处理）："…realize that there
  isn't currently any way to work around this need at present."

## 现有方案为什么不足

单指派是简化实现的选择，但把"协作"这个核心场景排除在了模型之外。

## 可能的解决方向

任务模型原生支持多负责人与角色分工（主责/协作/评审），报表按真实参与统计。

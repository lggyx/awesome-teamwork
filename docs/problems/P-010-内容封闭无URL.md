# P-010 内容封闭无 URL，分享与集成被卡

## 问题描述

把一个单据/内容分享给工具外的人，或让其它系统引用它时，发现内容根本没有
稳定 URL——只能把人也拉进同一个生态。中文社区对此的概括："都是要打造
封闭生态……都是要圈养用户"。

## 证据

- V2EX「我为什么反对使用钉钉来协作和办公」（48 回复，2019-01，至今有参考价值）：
  "钉钉没有 URL，如果要把一个内容、单子分享给其他人，只能使用钉钉"；
  jacketma："都是要打造封闭生态……都是要圈养用户"
  https://www.v2ex.com/t/530449
- Docmost#2764（补充，2026-11-22）：内网实例连"发单页给外部同事"都
  做不到，已升格 P-110。

## 现有方案为什么不足

封闭生态对买方是锁定价值，对使用者是协作摩擦；开放性（万物皆 URL）本该是
协作工具的底层设计而非营销话术。

## 可能的解决方向

一切内容默认有稳定、可鉴权的 URL；对外分享与 API 集成按权限开放。

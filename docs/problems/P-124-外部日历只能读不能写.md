# P-124 外部日历只能读不能写

## 问题描述

"It is frustrating that external calendars can only be added for
viewing... that functionality limitation impedes my family's entire
ability to use the Nextcloud Calendar app"——外部日历（CalDAV）
只能订阅查看，不能读写；用户的用例直接"阻碍整个使用"。
与 P-054（Deck CalDAV 只读）同属"标准协议半吊子支持"。

## 证据

- Nextcloud Calendar#2766（124 👍/34 评论）：原文如上
- Deck#2399（70 👍/13 评论）：同族证据

## 可能的解决方向

CalDAV 外部日历支持读写双向同步（衔接 P-054）。

# P-023 文档无标签/横向分类

## 问题描述

知识库用久了，文档只能挂在单一目录树下；想按项目、客户、主题等横向维度
过滤时没有手段，检索退化为碰运气的全文搜索。Outline 用户多年持续追问
标签系统，长期 open 无人实现。

## 证据

- Outline#765（134 👍 / 115 评论，长期 open）："I think tags would be a
  really useful addition to outline - is this something you have planned,
  or an idea how you want to implement it?"（首轮代理抓取，列入其报告主清单）

## 现有方案为什么不够

树形结构是唯一组织轴；标签、自定义元数据这类横向组织能力缺位，
规模化后检索成本线性上升。

## 可能的解决方向

文档模型原生支持标签/自定义元数据 + 按任意维度的筛选视图。

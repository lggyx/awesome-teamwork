# P-069 田园敏捷：流程表演的中文变体

## 问题描述

"开发眼里的敏捷，就是不写注释……老板眼里的敏捷，就是加班加班再加班。"——
朋友公司借敏捷之名临时凑团队开工，无人培训、无基础设施，已有人离职。
敏捷在中国中小团队的现实是压工期的话术包。

## 证据

- V2EX t729338（58 回复）：如上原文
- 小团队被强推 SCRUM（补充，SE score 26/10 答）：4-5 人自组织团队被
  强推 SCRUM——"为何每两周必须有可交付成果？为何全员必须参加规划会
  ——实际上只有少数人能真正拆解任务"
  （softwareengineering.stackexchange.com）

## 可能的解决方向

工具无法替团队正确，但可以拒绝为表演提供燃料：
不为"向上报表"设计功能（呼应 P-015/P-046/P-059）。

# P-134 工作流无法等待外部工作流

## 问题描述

工作流能等子工作流、外部客户端能按 id 等待，但"Ability waiting for
the completion of any workflow from a decider code is missing"——
跨系统/跨团队的任务编排停在边界上。对协作工具的意义：当一个请求
依赖另一团队/外部系统的流程时，状态无法自动汇聚（呼应 P-013 跨团队
交接、P-009 等待反馈）。

## 证据

- Temporal#680（76 👍/15 评论）：原文如上，2026-11-22 实抓

## 可能的解决方向

任务/请求支持跨系统等待原语（外部完成事件驱动），
等待状态对团队可见（衔接 P-009）。

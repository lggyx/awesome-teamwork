# P-027 自托管多端同步不可靠

## 问题描述

自建 AppFlowy-Cloud 的用户：网页端可以正常读写，桌面端（Linux/Windows
双平台复现）持续报 "Can't connect to sync changes"——同一账号同一服务，
端与端不同命。协作工具的同步层不可靠，直接动摇"数据在哪、可信吗"
这个根基。

## 证据

- AppFlowy#8130（25 评论，Linux/Windows 多平台复现）："I can access and
  write notes on the web version, but on PC Linux version (latest version
  0.9.5) or Windows 11, I always get error Can't connect to sync changes"

## 现有方案为什么不够

同步状态对用户不可见（无"最后同步时间/冲突队列"面板），故障诊断信息
为零；同步可靠性没有当作核心质量属性来验收。

## 可能的解决方向

同步状态透明化（每端最后同步时间、待同步队列、冲突可见可解）；
同步故障给可行动的自诊断输出。

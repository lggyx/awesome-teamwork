# P-032 按席位计费挡住协作参与

## 问题描述

协作工具天然需要"很多人看、少数人写"（干系人、客户、跨部门同事），
但计费按人头：想给全公司只读访问就得为数百个几乎不登录的账号买 license。
用户直接说 "I just don't want to have to purchase a License per User
for the whole company."——于是协作范围被计费模型人为缩小。

## 证据

- r/selfhosted「Confluence Alternative?」（47 分 / 80 评论），楼主：
  "I just don't want to have to purchase a License per User for the
  whole company."（正文经 redlib 镜像读取）
- 同帖邻证据：YouTrack 用户 "I had YouTrack setup and working great,
  until i realised it had a user limit."（r/selfhosted 1rj7zvr）
- Confluence 中国区（补充，V2EX t606980，86 回复）："100 个用户，1 年
  需要 10,200.00 美元，管理文档花这么多钱估计批不下来"
- 飞书配额墙（补充，sspai 98460）："企业人数上限 100 人、但笔者所在的
  部门超过了 100 人"；自动化动作每月 100 次配额。
- 企微双重收费（补充，App Store 评论 2026-11-20）："按照提示充值500元
  扩容至5000人，充完钱邀请人发现又不行，提示我企业未认证，需要认证后
  才可以，于是按照流程充值300认证费"——按提示付费仍被下一道墙拦住。

## 现有方案为什么不够

按席定价继承自企业软件时代，与"协作工具的价值在于连接更多人"直接矛盾。

## 可能的解决方向

计费按活跃写者、只读与外部协作者免费——若本项目涉及商业化，这是
定价模型的差异化点。

# P-033 知识库规模化后搜索失效

## 问题描述

知识库前几个月好用，页面数百之后检索崩塌："it's _extremely hard_ to
find the content that you're looking for. The search functionality is
completely broken at scale"（实测链接与热度一致：102 分 / 76 评论）。
中文场景更惨：Notion 模糊搜索范围太宽，"只能搜到字，搜不到词组"。

## 证据

- HN「Ask HN: Which Wiki or internal documentation tools do you use?」
  （102 分 / 76 评论），dmlittle："Now that we have hundreds of pages
  it's _extremely hard_ to find the content that you're looking for."
  https://news.ycombinator.com/item?id=18874707
- V2EX t/1030144（66 回复），45 楼："notion 搜索中文很不好用，模糊
  搜索范围很宽，只能搜到字，搜不到词组"

## 现有方案为什么不够

搜索不是知识库的事后插件而是核心资产检索层；标题/正文/标签权重、
中文分词、规模化索引都没被认真做。

## 可能的解决方向

把搜索当一级功能：中英文分词、标题高权重、标签过滤；规模化的性能
基准纳入验收。

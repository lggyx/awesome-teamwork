# P-125 工具沦为走过场积灰

## 问题描述

"用什么不重要，txt、excel 都能管理，关键是团队的人有操守没，见过
很多好的工具被最后用的只是走个流程，没发挥大作用"；
"这跟以前为了写日记一样买了一堆本子一样，其实没什么必要，写不了
两页就积灰了"——中文一线对工具价值的清醒认知：工具不是万灵药。
与 P-015（工具维护成本反噬）、P-048（上手成本击退新人）同族：
工具能否活下来，取决于它融入工作的成本是否足够低。

## 证据

- V2EX t365438（28 回复）：3/19 楼原话，2026-11-22 实抓
- 同帖 6 楼："学习曲线比较陡峭，特别是配置流程、设置报表图表什么
  的"——配置成本劝退

## 可能的解决方向

本项目设计原则：默认零配置可用，价值在第一周就能感知；
把"工具会不会积灰"作为验收问题之一。

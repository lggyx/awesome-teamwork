## 问题描述

code. To have any chance of being up to date, knowledge of the code
and functionality should be as close from the code as possible"；
以及"Obsidian is awesome for personal use, but a company-wide
Obsidian on a Google Drive just smells like a disaster waiting to
happen. No version control, no edit history."——个人笔记工具被硬套
到团队场景，缺版本与协作底座。

# P-063 聊天承载不了深度讨论与决策

## 问题描述

"slack is a poor medium for in depth questions and answers. It's a
chat application made for short text."；老队长的护栏："I've worked
hard to make sure slack isn't the place for decisions to be made that
are any greater than where to go for lunch."——但大多数团队没有这个
护栏，大决策都在错误的媒介里草率通过。

## 证据

- HN 31943016（92/106）：以上两条原文
- HN 19554550："it's an unstructured forum for ideas. I think it
  foments shallow commenting/debating over deeper conversations and
  planning."

## 可能的解决方向

讨论分层：聊天里一键升级为结构化议题/决策卡（衔接 P-049），
决议与理由脱离时间线持久存在。

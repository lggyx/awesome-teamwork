# P-090 黑盒分工

## 问题描述

小团队常见的"高效"分工是把模块与个人长期绑定。中文社区讨论（38 回复）
点破代价："黑盒意味着日常开发别人做 code review 无从下手，紧急时刻
别人无法替补，人员离职别人无法接手"；"如果不让其他人插手 就会导致
shi 山 越来越高"。与 P-072（交接靠人肉）互补：这是分工结构本身
制造的交接灾难。

## 证据

- V2EX t879876（38 回复）：以上原话（2/22/28 楼）

## 可能的解决方向

协作工具让"模块所有权 + 参与者图谱"可见（谁改过、谁能接手），
降低黑盒化的组织诱因。

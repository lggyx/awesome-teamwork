# P-091 周报表演化

## 问题描述

中文职场周报四重奏：员工问"写周报的意义何在？"（112 回复）；
写简单了被怀疑——"后来，我就因为周报太简单被老板怀疑我上班没使劲儿"，
而"形式主义，没一点用……让以为大家都很勤奋"；制度来源随意——
"别的老板和我吃饭吹牛逼时提了一下，感觉有点儿意思，回去就让行政搞了"；
连发起制度的管理者都自厌——《当我要下属写周报，变成了自己不希望成为的
人》（66 回复）。与 P-043（重复汇报层）、P-044（维护工作不可汇报）
构成汇报问题的完整闭环。

## 证据

- V2EX t724850（112 回复/浏览 14703）：43/76/78 楼原话
- V2EX t196843（66 回复）：管理者自述与回复
- V2EX t505106（30 回复）："一直没活干，周报都写不出来了，领导还不
  了解我这块"——没活干还得编周报的双重困境

## 可能的解决方向

汇报内容从工作流自动聚合（衔接 P-043），周报降级为"确认与补充"；
没有进展时允许如实留白。

# P-004 自托管部署依赖门槛高

## 问题描述

想自托管一个协作工具，先要搭好对象存储、数据库、反向代理一整套依赖：
Outline 强制 S3/Minio，用户直言"setting up Minio is the most difficult part
of hosting Outline"；AppFlowy 则连官方 Docker 镜像都缺（46 👍 / 36 评论）。

## 证据

- Outline#5716："setting up Minio is the most difficult part of hosting Outline"
- AppFlowy#13："I see .dockerignore, but no Dockerfile. Would love to see one!"

## 现有方案为什么不足

"自托管"的目标用户是小团队/个人，部署复杂度却按企业级设计。

## 可能的解决方向

默认最小依赖的单容器/单二进制发行形态，对象存储等作为可选插件渐进启用。

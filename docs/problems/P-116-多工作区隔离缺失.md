# P-116 多工作区隔离缺失

## 问题描述

Joplin 用户要"run multiple instances of Joplin… each with different
profiles"（99 👍 / 77 评论）；Element 的多账号请求 977 👍。
工具的"单工作区"假设与真实的多重身份（工作/个人/多客户）冲突。

## 证据

- Joplin#591（99/77）与 Element#2320（977/294）实抓

## 可能的解决方向

工作区/配置文件一等隔离（数据、通知、身份各自独立），
与 P-085（多账号）合并设计。

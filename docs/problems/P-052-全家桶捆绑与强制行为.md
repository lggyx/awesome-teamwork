# P-052 全家桶捆绑与强制行为

## 问题描述

只想用飞书文档的个人/小团队，必须下载整个飞书 IM——"我只需要一个
文档功能，但是需要整个 IM 工具"，独立的"飞书文档"App 已被官方砍掉
（前研发证实产品策略就是 all in one 不再拆分）。同类强制行为还有：
企微聊天里的链接强制用内置浏览器打开且无法关闭、飞书不更新不给用。

## 证据

- V2EX t/1071370（33 回复，实测链接与回复数一致），楼主："我只需要
  一个文档功能，但是需要整个 IM 工具。"；30 楼（自称飞书前研发）：
  "答案是要做 all in one 的集成工具，没有打算再拆成独立 APP"
- V2EX t/829398（96 回复），39 楼："更新到 4.0 大版本之后，聊天
  记录里的链接默认用内置浏览器打开，并且无法设置"；55 楼："今天
  打开飞书，强制更新才给用。路转黑。"

## 现有方案为什么不够

商业动机（DAU 口径、捆绑销售）与用户需要的能力单元错配；
厂商没有动力拆，用户没有选择权。

## 可能的解决方向

能力模块化：文档/看板/IM 可独立启用，权限与数据模型天然解耦。

# P-110 内网知识库无法安全外发单页

## 问题描述

安全要求高的组织把知识库只部署在 LAN/VPN，但远程/出差/无 VPN
的成员需要单页（流程、how-to、onboarding guide）时无路可走：
"today there is no way to do that"——要么全开放，要么全封闭，
没有"只发布这一页到公网、其余保持内网"的中间态。

## 证据

- Docmost Discussion #2764（2026-11-22 实抓）：提出 "Docmost
  Gateway" 独立组件，只把指定页发布到公网，主实例保持内网

## 可能的解决方向

页面级"发布为外链"能力（独立鉴权、可撤销、可设有效期），
主实例不必暴露（衔接 P-010 内容可分享、P-101 内外可见性分层）。

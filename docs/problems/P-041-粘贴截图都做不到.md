# P-041 粘贴截图都做不到

## 问题描述

报 bug、给反馈的最自然动作是 Cmd+V 一张截图，但看板工具的评论/
描述框不支持直接粘贴图片："That would save the step to save into a
file and upload that again..."。截图要落地成文件、命名、再走附件
上传——摩擦大到用户放弃配图，问题描述质量整体劣化。

## 证据

- Deck#533（36 👍 / 31 评论，open）："That would save the step to
  save into a file and upload that again..."
- Kanboard#4893："Anybody willing to add ability to paste image into
  description as part of ticket create and edit?"
- Basecamp iOS（补充，App Store 评论）："I kinda hate this app simply
  because I can't reliably attach a screen shot from my iPhone."——
  移动端截图都附不上。

## 现有方案为什么不够

把"粘贴"当富文本编辑器的锦上添花，而不是高频反馈路径的必经之路。

## 可能的解决方向

所有文本输入框支持剪贴板图片直粘（自动落对象存储、引用即成）。

# P-104 自托管集成靠人肉摆渡

## 问题描述

WeKan 的 GitLab 集成请求（45 👍）与 Rules 同步（36 👍）、Leantime
的 webhook 支持（9 👍）都是多年 open——自托管用户想要"任务↔代码↔
IM"的自动联动，只能人肉搬运。与 P-029（Git forge 集成）、P-053
（API 质量）同属集成真空带，这里强调的是长尾工具的集成荒漠。

## 证据

- Wekan#109（45 👍 / 51 评论）、#2698（36 👍）、Leantime#249（9 👍）

## 可能的解决方向

通用集成底座（webhook + 双向同步器 + 常见 forge/IM 连接器）
而非逐个硬编码。

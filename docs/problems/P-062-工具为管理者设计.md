# P-062 工具为管理者设计

## 问题描述

"It absolutely feels like a tool for managers, not developers. I just
want to see what I'm supposed to be working on... all of the rest is
noise to me."——与 P-020（买单人错位）互为因果：因为买家是管理层，
界面资源持续向管理视角倾斜。

## 证据

- HN「Looking for an Alternative to Jira」（60/78）原文如上

## 可能的解决方向

"我的今日工作"作为默认首页：每位成员打开即见自己的任务/阻塞/
待评审，管理视图按需进入。

# P-106 自托管被当二等公民

## 问题描述

AFFiNE 自托管用户的连环吐槽：界面显示"Affine Cloud"让用户分不清
连的是谁（57 👍）；demo workspace 不能关（44 👍）；"Self-hosted
not unrestricted"（30 👍）；客户端连自托管服务器是多年后才补的
基础能力（64 👍）。AppFlowy-Cloud 侧：自托管版隐藏的 1 用户限制
导致部署翻车（"Undocumented 1-User Limit in Self-Hosted Version
Causes Major Setup Issues"，14 👍）、发布到网页/模板在自托管不支持
（13+13 👍）。与 P-096（nagware）同族但更基础：自托管不是阉割问题，
是"根本没被当主要场景设计"。

## 证据

- 以上 6 条 GitHub issues 标题与热度实抓于 2026-11-20

## 可能的解决方向

自托管是一等公民：部署后体验与 SaaS 对齐（命名、可配置性、
功能完整性），能力矩阵公开透明。

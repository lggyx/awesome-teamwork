# P-083 消息发送延迟

## 问题描述

企微："我自己发出去的消息偶而几秒钟能发出去，大部分都要等到五六分钟
甚至半小时才能把消息发出去"——收消息正常、发消息延迟，基础通信
可靠性崩塌，用户被迫回到个人 IM 谈工作（数据与合规双双出逃）。

## 证据

- 2026-11-20 抓取的中国区 iTunes RSS 评论原文

## 可能的解决方向

发送延迟纳入服务端 SLA 监控；超时给出明确状态（排队/重试/失败）。

# P-129 开源软件变非自由

## 问题描述

Bitwarden 桌面版 v2024.10.0 引入 `@bitwarden/sdk-internal`，其许可证
含条款："You may not use this SDK to develop applications for use
with software other than Bitwarden (including non-compatible
implementations of Bitwarden) or to develop another SDK."——直接违反
自由软件定义第 0 条，桌面版不再是自由软件。用户无法从源码构建
（88 👍）。

## 证据

- bitwarden/clients#11611（88 👍/31 评论）：原文如上

## 可能的解决方向

与 P-113/P-128 同族：软件自由度的退化要可检测（依赖许可证审计
进 CI），本项目承诺许可证变更需社区共识。

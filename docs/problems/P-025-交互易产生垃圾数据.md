# P-025 交互易产生垃圾数据

## 问题描述

新建卡片后不做任何输入、直接关闭弹窗，仍会留下一张空卡片——
"It feels too easy to accidentally create cards that you didn't mean to."
小交互缺陷 × 高频操作 = 看板数据质量持续劣化，成员对工具数据的信任度下降。

## 证据

- Focalboard#4843（31 评论，仍 open）："A card isn't created automatically
  unless the user enters some text or makes some changes. It feels too easy
  to accidentally create cards that you didn't mean to."

## 现有方案为什么不够

工具默认"操作即创建"，没有无输入不落库、或空对象自动回收的设计。

## 可能的解决方向

空实体不持久化（失焦即弃）或定时自动回收；所有高频创建路径统一此原则。

# P-096 开源名义下的 nagware

## 问题描述

Plane 发布帖的评论成了开源信任质询会："Yet another 'OpenSource' PM
that makes basic features like custom fields paid"；"The self hosted
solution does not allow custom fields / theming or advanced
authentication controls"——自托管版锁自定义字段；"I got so frustrated
seeing all these features that were locked down unless I subscribed
to a monthly plan. It felt like nagware."与 P-030（回头加墙）不同：
这是**第一天就把墙画好**，"开源"成了获客话术。

## 证据

- Reddit r/selfhosted 13z5xr4（正文经 redlib 镜像读取，规范 URL 如上）

## 可能的解决方向

对本项目的治理承诺：开源版功能边界清晰公开，自托管不锁
基础协作能力，商业化走托管/团队/高级集成而非功能阉割。

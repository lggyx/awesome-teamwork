# P-094 值班排班靠喊话

## 问题描述

假期值班全落唯一本地员工头上（同事以"回老家没网"避班），无加班费、
旅行泡汤："因为不是全天候正常工作，所以没加班费。我特别不爽"；
回复直指本质："值班，本身就是个搞笑讲法，就是加班么，三倍工资"；
'"不是全天候工作，所以不算加班'，这算什么逻辑？"——值班/轮岗
没有工具化的公平轮换与补偿台账。

## 证据

- V2EX t168072（72 回复）：32/44/72 楼原话；同类讨论 t601996、
  t643795、t426425（值班制度怎么定）

## 可能的解决方向

排班轮换规则化（自动轮值、换班申请、补偿记录），值班与工单/
告警打通（衔接 P-009）。

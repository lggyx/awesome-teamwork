# P-019 开源协作工具维护连续性风险

## 问题描述

Focalboard 官方公开宣布"not currently being maintained"并征集新维护者，
存量用户被弃；Taiga 被社区质疑停滞（"As most of issues are not even
replied, and code seems to be still since 2020..."）。团队押注的工具
随时可能停摆。

## 证据

- Focalboard#5038（43 评论，官方 issue 仍 open）："This project is not
  currently being maintained and we are looking for community members, with
  past experience maintaining open source projects, who are interested in
  becoming maintainers of this project."
- taiga-back#111："As most of issues are not even replied, and code seems to
  be still since 2020..."
- V2EX t/1027053（补充，42 回复/浏览 11030）：语雀衰退焦虑——"客户端
  经常打不开……从上午一直按到下午才把客户端打开"；"自从不开会员禁止
  分享功能，就卸载了"。存续风险不限于开源，SaaS 同样让用户睡不着。

## 现有方案为什么不足

开源不等于可持续；用户选型时看不到维护健康度信号，也无法低成本迁出
（叠加 P-018）。

## 可能的解决方向

对用户侧：数据可迁出能力 + 标准化数据格式是对冲；对本项目自身：
这是公开运营时要向用户证明的点。

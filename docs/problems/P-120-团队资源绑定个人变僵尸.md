# P-120 团队资源绑定个人账号变僵尸

## 问题描述

团队日历只能由个人创建再分享，"the calendar is always connected
to this user. The construct breaks down if the person is not longer
part and the account will be deleted. In this view the calendar-owners
must/will live as zombies (undead accounts)."——为了让团队资源活下去，
只能保留死人账号。这与 P-081（离职数据失继）、P-072（交接靠人肉）
同根：**资源的所有权模型是"个人"而非"团队"**。

## 证据

- Nextcloud Calendar#3044（43 👍/7 评论）：原文如上，用户要求
  "A Calendar that is connected to a group would be nice. Like a group
  folder."

## 可能的解决方向

团队资源一等化：日历/项目/知识库可归属 group 而非个人，
成员变动自动重指派（衔接 P-081/P-026）。

# P-123 用户生命周期跨系统不同步

## 问题描述

Zitadel 用户要"outbound SCIM provisioning… ensure users exist in
external applications before SSO login attempts and maintain
consistent user lifecycle management across multiple applications"
（66 👍/9 评论）；用户组授权（137 👍）、跨组织移动用户（24 👍）
同族。人的入职/离职/转组在 N 个协作工具间靠人肉同步，
必然产生孤儿账号与权限残留（与 P-028 删用户还发通知、P-081 离职
数据失继同链）。

## 证据

- 以上 3 条 Zitadel issues 标题与热度实抓于 2026-11-22

## 可能的解决方向

SCIM 入站+出站双向同步，账号生命周期事件驱动
（入职即开通、离职即回收并转交资源）。

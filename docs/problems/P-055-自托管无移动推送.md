# P-055 自托管无移动推送

## 问题描述

移动推送依赖厂商通道（APNs/FCM），多数开源自托管工具要么不接、
要么强制走官方中继。Twake 自托管用户直接掉线：
"On-premise mobile app push notifications are not available"
（该库热度第一，54 👍）。与 P-009（通知已读不回）不同：
这是通知根本到不了手机。

## 证据

- twake-legacy#130（54 👍 / 3 评论，open）："On-premise mobile app
  push notifications are not available" / "A way to configure the
  notification pusher to use the official Twake App as relay."

## 现有方案为什么不够

隐私与触达的矛盾没有被产品化：不想过厂商通道就没有替代通道
（自建 WebSocket 常连、统一推送联盟等方案缺位）。

## 可能的解决方向

推送通道可选（官方中继 / 自托管直连长连接），管理员按安全
要求自选，不把移动成员牺牲掉。

# P-103 工时记录的信任战争

## 问题描述

HN 十年如一日地问："Are Time Tracking Applications Worth It"、
"Is Time Tracking Useful?"——工时数据到底服务谁？开源工时工具
Kimai 的用户也在要"Timer + Billable + Reporting"（#2521）。
填报被当监视就失真，不填管理层就另造影子数据（呼应 P-046）。

## 证据

- HN 19224445（9/5）、34640739（1/4）；Kimai#2521（8 👍）

## 可能的解决方向

工时自动采集为主（任务流转/日历），填报降为校准；
数据用途契约化（明确不进绩效）。

# P-003 自托管实例响应极慢

## 问题描述

自托管部署在数据量上来之后性能断崖：Leantime 管理员每次点击页面约 15 秒
（PHP 进程池打满）；Wekan 升级后 ferretdb CPU 100%+，除登录页外一切极慢；
Wekan 大看板加载"extremely slow"。

## 证据

- Leantime#2355（14 评论）："every click inside leantime takes around ~15s"
- Wekan#6480（18 评论多人复现）："ferretdb above 100 % CPU usage, and loading
  anything apart from the initial login screen is extremely slow."
- Wekan#6745："one board is very large, and the loading times are extremely slow"
- Focalboard#560（补充）：插件模式下 "It takes a few seconds for the UI to
  update"——性能劣化不只发生在独立部署，插件形态同样中招。

## 现有方案为什么不足

性能问题以 issue 形式长期存在，产品侧没有性能预算（多任务/多卡/多大板下
目标响应时间），用户无从判断工具能否扛住自己的规模。

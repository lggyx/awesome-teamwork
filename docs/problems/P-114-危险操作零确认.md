# P-114 危险操作零确认

## 问题描述

"It's too easy to delete a space and this action cannot be undone.
Today I deleted a space with a similar icon to an empty one and lost
quite a bit of data."——相似图标 + 一键删除 + 不可撤销。
与 P-051（误删重要数据）同族，这里是"整个工作空间"级别的误删。

## 证据

- Anytype#946（16 👍/6 评论）：原文如上，用户建议"输入名称确认"

## 可能的解决方向

高风险删除强制输入名称确认 + 软删除回收站（衔接 P-051）。

# P-115 附件内容不可检索

## 问题描述

"it is possible to attach PDF files to notes... but the content of
those PDF files doesn't get searched when the user enters a search
string"——PDF/Office 附件里的文字对搜索完全不可见。知识库用户
越来越依赖附件承载干货，检索盲区却越来越大。

## 证据

- Joplin#485（66 👍 / 24 评论）：原文如上

## 可能的解决方向

附件入库即抽取文本建立索引（OCR + 全文检索），
附件内容与主文档统一检索（衔接 P-033）。

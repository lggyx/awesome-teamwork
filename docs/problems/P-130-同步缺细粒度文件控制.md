# P-130 同步缺细粒度文件控制

## 问题描述

两台设备断网期间各自改了文件，恢复同步时没有直接手段"只把 A 的
某个文件同步到 B"或"只从 B 删某个文件"——只能整目录人工处理。
77 👍/5 评论的需求长期 open。协作工具的文件/知识同步如果只支持
"全有或全无"，冲突处理就会退回人工。

## 证据

- Syncthing#9083（77 👍/5 评论）：原文描述如上，2026-11-22 实抓

## 可能的解决方向

文件级同步决策（选择性拉取/删除、冲突保留双版本），
与 P-027（同步不可靠）、P-036（协同覆盖）同族。

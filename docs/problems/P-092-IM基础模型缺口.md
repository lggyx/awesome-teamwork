# P-092 IM 基础模型缺口

## 问题描述

Rocket.Chat 全库前三的请求是 Threads（303 👍）和群私信（298 👍）；
Zulip 用户想要"私信也能开 topics"（36 👍）；Element 的线程消息
（313 👍）做了多年才落地。IM 工具的信息组织基本盘（线程、群私信、
频道内检索）反复被当"进阶功能"推迟。

## 证据

- 以上 4 条 GitHub issues 标题与热度实抓于 2026-11-20
  （Rocket#1112/#4489 为 closed 后实现，佐证该需求长期积压）

## 可能的解决方向

信息组织模型一次做对：会话=可线程化，群聊=一等对象，检索跨会话。

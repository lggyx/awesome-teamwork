# P-131 权限不跟随标签

## 问题描述

"I want to automatically grant access to user based on his role to a
specific list of tags"——Airflow 的权限只能按单个 DAG
（"can dag read on <dag name>"），无法按 tag 批量授权。与 P-034
（权限粒度粗）互补：这是"权限与内容分类脱节"——标签是天然的分类
维度，权限系统却视而不见。

## 证据

- Airflow#9342（36 👍/28 评论）：原文如上，2026-11-22 实抓

## 可能的解决方向

权限规则支持按标签/属性表达（ABAC 雏形），
新资源带标签即自动继承权限。

# P-081 离职/注销流程断裂数据失继

## 问题描述

企微："我的账号被删除后，管理后台无任何离职记录、无离职继承入口……
完全无法同步、找回原来账号的任何聊天、群聊、文件、权限等所有数据"；
飞书注销流程："创建账号时不经我确认系统给我创办一个企业，注销账号
需要离职，离职需要移交文件，又不能移交给自己"——账号生命周期的
出口被设计成了迷宫。

## 证据

- 两条均为 2026-11-20 抓取的中国区 iTunes RSS 评论原文

## 可能的解决方向

离职/注销作为一等流程：数据继承清单、接手人指定、离职保留期，
全程可追踪（衔接 P-072 交接）。

# P-112 协作白板基础能力缺失

## 问题描述

主流开源白板连"画个表格"这种基础需求都没有：Excalidraw 的表格
模板（327 👍/147 评论）用户"spent several days looking for a
solution - but to no avail"；文本高亮（243 👍）、文本颜色区间（170 👍）、
LaTeX（87 👍）；tldraw  likewise 缺表格与 Mermaid 自动绘制。
白板作为协作产物载体，基础表达都残缺。

## 证据

- 以上 6 条 GitHub issues 标题与热度实抓于 2026-11-22
  （excalidraw#4847 评论原文："having a table in the Excalidraw Library
  is very necessary"）

## 可能的解决方向

白板不再是"画图玩具"：表格/富文本/公式等结构化组件是一等公民，
产物可回链到任务/文档。

# P-036 文档协同编辑缺失、互踩覆盖

## 问题描述

多人共写一篇文档时没有冲突检测，"the most recent person to save just
overwrites the other"——工作直接丢失。这是 BookStack 全库最热的请求
之一（94 👍 / 65 评论），2026-04 被官方批量关闭仍未实现。

## 证据

- BookStack#395（94 👍 / 65 评论，closed 未实现）："Currently if you
  have multiple people editing the same document, the most recent person
  to save just overwrites the other."

## 现有方案为什么不够

实时协同（OT/CRDT）工程门槛高，多数开源知识库选择不做；用户侧的
后果是"共写"这个基本协作动作不敢发生。

## 可能的解决方向

最低配也要有编辑锁与冲突提示；进阶做段落级合并。对本项目：若做文档，
协同编辑是绕不开的核心投入。

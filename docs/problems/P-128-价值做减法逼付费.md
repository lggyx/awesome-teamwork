# P-128 "价值做减法"逼付费

## 问题描述

一封致 Windmill 团队的公开信（28 👍，作者后来撤回部分措辞但仍保留记录）
系统控诉"value subtracted"式商业化：自托管还按 worker 数和内存收费
（"pay to use their own compute"）；CE 版 S3 只能列 20 个对象/传 50MB；
搜索依赖已下载本地却不让用；私有 PyPI/NPM 不支持；关键流程失败
告警要付费。作者的结论："if it said 'Open core' or 'Source available'
from the start, I wouldn't be writing this issue… Open Source is—and
should always be—more than just a marketing term."

## 证据

- Windmill#5014（28 👍/8 评论）：完整公开信原文，2026-11-22 实抓

## 可能的解决方向

本项目治理承诺（强化 P-096）：商业化为"value added"而非"value
subtracted"；许可证名实相符（开源就全开源，open core 就明说）。

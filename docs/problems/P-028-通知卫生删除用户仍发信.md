# P-028 通知卫生：删了用户还发邮件

## 问题描述

用户被删除后，系统仍向其邮箱发送任务逾期提醒——通知体系与账号生命
周期脱钩。这类小问题单独看不重，但直接消耗工具的信任：成员收到
"幽灵邮件"，管理员说不清系统还会干什么。

## 证据

- Vikunja#1581：已删除用户仍收逾期邮件（deleted users keep receiving
  overdue task emails）

## 现有方案为什么不够

通知发送链路没有校验收件人的存在与状态；账号删除不级联清理订阅。

## 可能的解决方向

通知发送前的收件人状态校验；删除用户的级联清理清单（订阅/令牌/webhook）。

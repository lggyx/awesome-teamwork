# P-111 审批流被编辑后失效

## 问题描述

"if a colleague edits a document that's already been approved, it
remains approved"——审批状态与内容版本脱钩，一改就失效的审批
流在合规场景（ISO 9001）下等于没有。用户要求可定制工作流。
这是 P-037（发布无审核流）的进阶形态：有审核流也不闭环。

## 证据

- Docmost Discussion #2620（2026-11-22 实抓）：组织用 Docmost 管
  HR/交付/客户文档，原文如上

## 可能的解决方向

审批绑定到内容版本，任何编辑自动降级为"待重审"；
工作流可配置，满足合规审计链。

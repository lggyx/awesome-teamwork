# P-119 自托管白板部署碎片化

## 问题描述

Excalidraw 的自托管伞形 issue（136 👍/149 评论）：客户端、socket
server、store server 三组件分家，各跑各的（Node.js + Python GAE），
跨域配置（allowlist）繁琐。社区只能自建单二进制方案："created a
bundle - single binary - which will work for selfhosting on mac/win/
linux/raspberry pi"——官方缺席，社区手搓。

## 证据

- Excalidraw#1772（136/149）正文与评论，2026-11-22 实抓

## 可能的解决方向

自托管一键包（单容器/单二进制），组件边界对管理员透明
（衔接 P-004/P-106）。

# P-132 开源名不副实的信任危机

## 问题描述

n8n 一个 issue（269 👍 / 403 评论）标题即为控诉："n8n is not open
source and your project is gaslighting its users"——作者指出 Commons
Clause + Apache 许可证组合制造虚假印象："Your software is rightly
called 'source available'. Do not gaslight us."并引用 xkcd 的比喻：
把安慰剂贴在真药旁边卖。与 P-128（value subtracted）、P-129（开源
变非自由）、P-113（去 Open 化）一起，构成 2026 年协作/自动化工具
领域最强烈的用户情绪：**受够了假开源**。

## 证据

- n8n#40（269/403）：完整控诉原文，2026-11-22 实抓

## 可能的解决方向

本项目把"许可证诚实"写进治理：MIT 就是 MIT，商业版明说；
这条本身就是对同类工具用户的差异化吸引点。

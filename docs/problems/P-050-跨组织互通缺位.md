# P-050 跨组织互通缺位

## 问题描述

两个组织各自自托管协作实例后无法互通（federation）：
"It would be great if multiple Zulip servers were able to talk to
each other."（Zulip 全库热度第一的 open issue，64 👍）。
甲方乙方、联盟型组织的共同工作区没有开源自托管答案，
只能把跨组织协作塞回邮件或某家的 SaaS。

## 证据

- Zulip#356（64 👍 / 48 评论，open）："It would be great if multiple
  Zulip servers were able to talk to each other."

## 现有方案为什么不足

SaaS 有"外部协作者"概念但以某方数据出境为代价；开源自托管
普遍没有实例间协议（federation 在 IM 领域只有 Matrix 成熟）。

## 可能的解决方向

长期方向：受控跨实例共享（空间/频道级邀请外部组织）；
短期至少做好"外部访客"角色的细粒度权限。

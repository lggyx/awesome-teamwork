# P-056 中文团队的两头难

## 问题描述

中文团队的知识协作选型是双向挤压：Notion"实在无法忍受 notion 速度"、
"移动端就是网页套壳做的跟一坨 X 一样"；国产平替 wolai"代码片段免费
用户不能超过 5000，充钱又怕跑路"（144 回复的高热帖）。
与 P-017（轻重断层）不同维度：这是**中文语境**下的可用性与
存续性双缺口。

## 证据

- V2EX t/817134（144 回复 / 浏览 23179，2021-11）：17 楼"我选 wolai，
  实在无法忍受 notion 速度。"；79 楼"Notion 移动端就是网页套壳
  做的跟一坨 X 一样，实在没法把它留在手机上。"；35 楼"wolai 代码
  片段免费用户不能超过 5000，充钱又怕跑路"

## 现有方案为什么不够

国际产品不为中国市场优化（速度/分词/移动端）；国产仿品商业化
短视 + 存续焦虑。P-033（中文搜索差）是本卡的子问题。

## 可能的解决方向

中文一线体验（速度、分词、移动端原生）+ 开源自托管消除跑路焦虑
——本项目的天然生态位之一。

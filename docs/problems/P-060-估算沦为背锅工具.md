# P-060 估算沦为背锅工具

## 问题描述

"they ask me how much time a certain task will take, but they still
go with whatever time the PM/Manager thinks… then they complain when
things get late."；更狠的形态是"a vague, hand-wavey estimate is
turned into a signed guarantee, then the developer gets disciplined"。
中文镜像："客户每次提一点东西都要估时间……估多了客户走估少了坑自己"。

## 证据

- HN 33276842（20/38）：以上两条英文原文
- V2EX t441361（23 回复）：如上中文原文（正文经 SoV2EX API 读取）
- 深挖补充（40969693 帖）：站会被反复追问日期"There's a conflict
  between what we can possibly know and what the client 'needs' to
  know"；替代实践：用数量级区间代替精确承诺——"is it a day, a week,
  a month, or a year?"

## 可能的解决方向

估算与承诺分离：估算区间可见、变更触发重估、责任回到变更决策者。

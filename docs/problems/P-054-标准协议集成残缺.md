# P-054 标准协议集成残缺

## 问题描述

Nextcloud Deck 的卡片能在日历/任务客户端里看到，但改不动——
CalDAV 集成是只读的。用户等这个功能等了多年："Full CalDav
integration is the feature I have been waiting for since the release
of Deck and would make me switch to Deck for all task management."
（70 👍）。标准协议半吊子支持（能读不能写），用户的既有工具链
就接不进来。

## 证据

- Deck#2399（70 👍 / 13 评论，open），评论原文如上

## 现有方案为什么不足

把标准协议当营销 checkbox 而非互操作承诺；只读实现省事，
但把用户锁死在自家 UI 里。

## 可能的解决方向

支持的协议就做双向（CalDAV/CardDAV/WebDAV/ActivityPub 路线），
不支持就明说——半吊子比没有更伤信任。
